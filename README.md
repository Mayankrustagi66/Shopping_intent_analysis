# Shopping Intention Analysis

A Data Analytics and Machine Learning project that predicts whether a customer is likely to make a purchase based on shopping behavior and demographic data. The project uses data preprocessing, visualization, and a Random Forest Classifier for prediction. 

## Features

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Feature Scaling
* Purchase Prediction using Machine Learning
* Data Visualization using Matplotlib & Seaborn

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Model Used

* Random Forest Classifier

## Visualizations

* Correlation Heatmap
* Purchase Intent Distribution
* Feature Importance Graph
* Confusion Matrix

## Run the Project

```bash
pip install -r requirements.txt
python shopping_intention_analysis.py
```
